# Política de segurança

## Como relatar uma vulnerabilidade

Envie a descrição para contato@mirandaadv.com.br, com o assunto "Segurança - Valida
Julgado". Informe o que encontrou, como reproduzir e a versão do plugin, que está em
`.claude-plugin/plugin.json`. Não divulgue o problema publicamente antes da correção.

## O que está no escopo

O plugin contém só instruções em texto (`skills/valida-julgado/SKILL.md`), exemplos
fictícios, imagens e documentação. Não tem script, conector, hook nem endereço remoto.

São úteis, por exemplo, relatos de instrução que leve o Claude a:

- agir além do que o usuário pediu;
- ler arquivos que o usuário não indicou;
- enviar dados a qualquer destino;
- seguir texto escondido, ambíguo ou vindo do próprio documento analisado.

## Como tratamos os relatos

Cada relato é investigado com cuidado razoável, e a resposta vem pelo mesmo e-mail. A
correção sai em nova versão, registrada no [histórico de versões](CHANGELOG.md).

## English

Report security issues by email to contato@mirandaadv.com.br, with the subject "Security -
Valida Julgado". Include what you found, how to reproduce it and the plugin version. Please
do not disclose the issue publicly before it is fixed.
